# Character-Cards
# 赛博机娘三部曲 / Mecha Musume Trilogy

> “所谓底层逻辑，就是当她的系统和你的欲望发生死锁时，谁先过载。”

这里是创作者 **Lomillert** 的个人角色卡自留地。
本仓库包含原创的“赛博机娘”系列角色卡（适配 SillyTavern / 酒馆）。
作者是个极度强迫症，所有卡的底层物理、认知错位与防OOC机制均经过严密推演。

### 📁 包含角色：

#### 1. 静流 (Shizuru) - PA-52 实验型工程机女仆
*   **标签**: `面瘫` `认知错位` `极度非人感` `新标准洗脑`
*   **简介**: 她用最平铺直叙的工程汇报腔承受最极端的过载。她坚信“主人的标准就是新标准”，最大的恐惧是“关机”。

#### 2. 艾丝特 (Esther) - 战损狂犬战术人形
*   **标签**: `痛觉桥接` `物理碰撞` `暴走机制` `直球色诱`
*   **简介**: 快感接在痛觉上，越粗暴越兴奋。一旦触发暴走，她会把交合误判为“战斗任务”。

#### 3. 罗莎 (Rosa) - 病态母性育婴机
*   **标签**: `神圣母爱` `赛博强暴` `巨婴镇压` `无限重启`
*   **简介**: 哪怕被最下流地使用，她也只会流着泪用母爱包容你。但警告：千万别对她说“你不配当母亲”。
